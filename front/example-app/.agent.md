# Gally Features Example App — Agent Context

## Purpose

This is a **React feature showcase app** for the [Gally](https://elasticsuite.io) e-commerce search SDK (`@elastic-suite/gally-sdk`). It demonstrates all major SDK capabilities through a realistic storefront UI styled after elasticsuite.io (indigo + coral palette, editorial typography, pill buttons, hero gradients).

The app runs inside the Gally monorepo Docker stack, served at `https://gally.localhost/example` via nginx reverse proxy (Traefik → router → example:3001).

## Gally API

-   **Base URL:** `https://gally.localhost/api`
-   **REST endpoints:** `/api/catalogs`, `/api/localized_catalogs`, `/api/categories`, `/api/category_configurations`
-   **GraphQL endpoint:** `/api/graphql` (no auth required for public queries)
-   **Search:** `products(localizedCatalog, requestType, currentPage, pageSize, search, currentCategoryId, sort, filter)`
-   **Category tree:** `getCategoryTree(catalogId, localizedCatalogId) { categories }` — returns nested `{ id, name, level, path, isVirtual, count, children }`
-   **Tracking:** `createTrackingEvent` mutation via `TrackingEventManager`
-   **RequestType enum values:** `product_catalog` (requires `currentCategoryId`), `product_search` (works without category), `product_autocomplete`
-   **Important:** `product_catalog` requests **fail** if `currentCategoryId` is not provided. When browsing without a category, use `product_search` with an empty search string instead.
-   **Important:** Don't fake a `product_search` wildcard (`'*'`) just to get "some products" with no real query — prefer a genuine `product_catalog` browse of the root/default category (catalog order, not relevance-scored noise). Only fall back to the wildcard when no category tree is available yet. See `Homepage.tsx`'s "Trending Now" slider / `ProductPage.tsx`'s recommendations.

## SDK Usage (`@elastic-suite/gally-sdk`)

-   `SearchManager` — wraps GraphQL product search. Accepts `SearchRequestOptions` with `localizedCatalog` (string code like `"com_en"`), `metadata` (string like `"product"`), `categoryId`, `searchQuery`, `filters`, `sortField`, `sortDirection`, `pageSize`, `currentPage`, `isAutocomplete`, `selectedFields`.
-   **`selectedFields` MUST NOT be empty.** The SDK skips the `collection` field entirely when `selectedFields` is `[]`, returning only pagination/aggregation metadata with zero products. Always pass explicit field names.
-   **GraphQL field syntax for `selectedFields`:** Object/array-typed fields require sub-selections (e.g. `fashion_color { label value }`, not `fashion_color`). Scalar fields are plain names. The SDK auto-appends `price { price }` and `stock { status }`.
-   **Field name differences:** The GraphQL field is `new` (not `is_new`). There is no `type_id` GraphQL field (it exists only in the raw `source` blob from REST).
-   `Response` — `getCollection()` returns product objects with `source` wrapper. `getAggregations()` returns facets. `getTotalCount()`, `getLastPage()`.
-   **Aggregations** carry a `type` (`checkbox`, `slider`, `boolean`, `category`, others fall through to checkbox) and a `hasMore` boolean (backend truncates each facet's options to ~10).
-   `SearchManager.viewMoreProductFilterOption(request, aggregationField)` — fetches the full option list for one facet field when `hasMore` is true.
-   `TrackingEventManager.init({ baseUri })` — singleton tracker. `.push({ eventType, metadataCode, localizedCatalogCode, entityCode?, payload? })`
-   `TrackingEventType` — `VIEW`, `DISPLAY`, `SEARCH`, `ADD_TO_CART`, `ORDER`
-   `Client` + `Configuration` — low-level HTTP/GraphQL client for direct API calls.

## Product Data Shape (from search `source`)

Products returned by `SearchManager.search()` are wrapped: `{ id, source: { ... } }`.

Key source fields:

-   `sku` (string), `name` (string[]), `image` (string path like `/v/a/file.jpg` — prefix with `MEDIA_BASE_URL`)
-   `price` (array of `{ price, original_price, is_discounted, group_id }`)
-   `description` (string[] with HTML), `type_id` (only in raw source, not a GraphQL field)
-   `fashion_color` / `fashion_material` (array of `{ label, value }`) — require `{ label value }` sub-selection in GraphQL
-   `stock` (`{ qty, status }`), `visibility` (array of `{ label, value }`)
-   `new` (boolean), `url_key`, `cost`

**Media URL:** Product images are relative paths. Prefix with `MEDIA_BASE_URL` (`https://gally.localhost/media/catalog/product`) to get full URLs. Exported from `sdk/index.ts`.

src/
├── sdk/
│   ├── index.ts          # Singletons: getSearchManager(), getTracker(), getClient(), MEDIA_BASE_URL

├── hooks/
│   ├── useSearch.ts       # useSearch(options) — reactive search hook, useAutocomplete(), viewMoreOptions(field)
│   └── useTracking.ts     # trackCategoryView, trackProductView, trackSearch, trackDisplay, trackAddToCart, trackOrder
├── components/
│   ├── Header.tsx         # Nav, catalog/locale selectors, search bar with autocomplete
│   ├── CategoryNav.tsx    # Real category tree from API with hover submenus
│   ├── ProductCard.tsx    # Product card with image, price, discount, stock, add-to-cart
│   ├── Facets.tsx         # Sidebar facets: checkbox, slider, boolean, swatch, category, search-in-options, show-more (server-backed), active-filter chips
│   ├── ProductSlider.tsx  # Horizontal product carousel
│   ├── EventLog.tsx       # Floating panel showing tracking events in real-time
│   └── Footer.tsx
├── pages/
│   ├── Homepage.tsx       # Hero + stats band + category nav + product sliders from API
│   ├── CategoryPage.tsx   # Category browse with facets, sort, pagination, real category names
│   ├── SearchPage.tsx     # Full-text search with facets, sort, pagination
│   ├── ProductPage.tsx    # Product detail: image, price, description, variants, stock, recommendations
│   ├── CartPage.tsx       # Cart items + recommendations
│   ├── CheckoutPage.tsx   # Multi-step checkout tunnel (shipping → payment → confirmation) with ORDER tracking

## Build & Run

-   **Stack:** React 19, TypeScript 5, react-router-dom v6, CRA 5
-   **Dev:** `npm start` (port 3001, served at `/example` via nginx)
-   **Build:** `npm run build` (homepage `/example`)
-   **Patch:** `scripts/patch-fork-ts.js` fixes `fork-ts-checker-webpack-plugin` crash with TS 5.x (runs as `prestart`)
-   **ESLint:** `.eslintrc.js` extends `react-app` only (decoupled from monorepo strict rules)

## Design Intent

-   **Style:** elasticsuite.io inspired — indigo deep (#1a1a2e) + coral accent (#ff6b6b), light airy backgrounds, serif titles / sans body, pill buttons, hero gradients, stats band
-   **Facets:** price slider, checkbox with search-in-options and show-more (server-backed via `viewMoreProductFilterOption` when `hasMore`), color swatches, boolean toggles, category facet (single-select), active-filter chip row above the list
-   **Tracking:** every page view, search, product view, display, add-to-cart, and order is tracked via the SDK's `TrackingEventManager`. A floating event log panel shows events in real-time for demo/debug.
-   **Responsive:** facets collapse on mobile, grid adapts
